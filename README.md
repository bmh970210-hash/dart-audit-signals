# DART Audit Signals | 감사 이상징후 탐지 MVP

OpenDART 공개 재무정보를 가져와 3~5개년 추이를 계산하고 규칙 기반 재무 이상징후를 감사주장과 후속 감사절차에 연결하는 교육·포트폴리오용 도구입니다.

## 현재 지원 기능

- 회사명/종목코드 검색: 금융감독원 `corpCode.xml` ZIP 자료 조회
- 사업보고서(11011) **단일회사 전체 재무제표**: `fnlttSinglAcntAll.json`
- 연결(CFS) 또는 별도(OFS)를 **선택하여 연도별 일관 적용**
- 매출액, 매출채권, 재고자산, 영업이익, 영업활동현금흐름 추출 + 3~5개년 분석
- 6가지 규칙 기반 이상징후, 관련 감사주장 및 검토 절차 안내
- DART 계정명/계정 ID/원문 접수번호 표시, 분석 결과 CSV 내보내기
- API 키 없이도 작동하는 **완전 가상 예시 모드**

**주의:** 이것은 정식 감사 소프트웨어가 아니며, 이상징후는 회계부정이나 왜곡표시의 확정 근거가 아닙니다. XBRL *주석* 분석과 AI 분석은 아직 구현되지 않았습니다. 현재는 DART 재무제표의 표준계정 ID를 사용합니다.

## 사용 1: 설치하지 않고 온라인 배포하기 (Windows 7, 태블릿도 사용 가능)

1. [OpenDART](https://opendart.fss.or.kr/) 가입 후 **인증키 신청** (키를 GitHub 등에 올리지 마세요).
2. GitHub에서 새 저장소(`dart-audit-signals`)를 만들고 **이 압축 파일의 내용물**(`app.py` 등)을 업로드하세요. ZIP 자체를 업로드하는 것이 아니라 압축을 푼 **개별 파일**이 필요합니다. `.streamlit/config.toml` 파일이 누락되어도 앱의 기능은 동작합니다.
3. [Streamlit Community Cloud](https://share.streamlit.io/) 접속 → GitHub로 로그인 → `Create app` → 방금 만든 저장소 선택 → `app.py` 지정 → `Deploy`.
4. 앱에서 `실제 DART 조회`를 선택하고 OpenDART 인증키를 암호 입력칸에 붙여넣은 뒤 회사명을 검색합니다. 공유 링크를 공개할 경우 키를 앱의 코드/레포에 적지 마세요.

## 사용 2: PC에서 직접 실행하기 (권장 Python 3.11~3.13 / 최신 OS)

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

윈도우 7 구형 환경에선 최신 파이썬 및 브라우저 지원이 제한됩니다. **클라우드 배포 경로를 권장**합니다.

## 규칙 (사업보고서 당기 금액 기준)

| 규칙 | 조건 | 감사상 후속 검토 단서 |
| --- | --- | --- |
| R01 | 매출 성장률 ≥ 30% | 매출 발생사실 및 기간귀속 |
| R02 | 매출채권 성장률 − 매출 성장률 ≥ 20%p | 실재성, 평가, 기간귀속 |
| R03 | 기말 매출채권/매출×365 전년 대비 증가 ≥ 20일 | 회수가능성 및 실재성 |
| R04 | 재고 성장률 − 매출 성장률 ≥ 20%p | 실재성 및 평가 |
| R05 | 영업이익 양수, 영업현금흐름 음수 | 수익인식과 회수가능성 검토 단서 |
| R06 | 매출 증가 중 CFO 양수→음수 | 현금화 괴리 분석 |

성장률은 전기금액이 **양수**인 연속 연도에만 계산합니다. 결측값은 0으로 대체하지 않습니다.

## 프로젝트 파일

- `app.py`: Streamlit 사용자 화면
- `dart_client.py`: OpenDART API 접속, 회사 검색
- `analysis.py`: 계정 매핑, 재무분석, 위험규칙
- `sample_data.py`: 실제와 무관한 가상 재무제표
- `tests/test_analysis.py`: 기본 자동 테스트
- `requirements.txt`: 필요 패키지 목록

## 데이터 품질 및 제약

- OpenDART의 `fnlttSinglAcntAll`은 **전체 재무제표** 정보를 제공하며 원문 XBRL 주석 파싱은 아직 미구현입니다.
- 사업보고서 `thstrm_amount`(당기)를 각 연도별로 가져옵니다. 정정보고서, 소급 재작성, 연도별 정책변경/사업결합 등은 별도 검토가 필요합니다.
- 매출채권 단독 계정이 없고 '매출채권 및 기타유동채권'만 확인되면 대용치를 사용했다고 명시합니다.
- 표준계정 ID 및 일부 정확 일치 명칭을 탐색합니다. 기업이 독자적으로 붙인 계정명은 미매핑 처리될 수 있습니다.
- 연간 매출/영업현금흐름이 비교 가능한 원화 표시액이라는 가정을 전제로 합니다. 원본 통화를 함께 제공합니다.
- 대용 DSO는 실제 회전일수와 차이가 있을 수 있습니다.

## 향후 확장

1. 원문 XBRL 주석(수익인식, 대손충당금, 재고 평가정책)
2. 동종 기업 비교와 산업별 기준치
3. AI 위험 설명(사용자 승인 후, 수치 출처 포함)
4. 가상 분개기록을 이용한 JET(분개 테스트)
